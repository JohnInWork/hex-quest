═══════════════════════════════════════════════════════════
  РЕКОМЕНДАЦИИ ПО РАЗМЕРУ:
═══════════════════════════════════════════════════════════

• Рекомендуемый размер: 64x64 пикселей или больше
• Формат: PNG с прозрачным фоном (для объектов и персонажей)
• Формат: PNG без прозрачности (для текстур земли)
• Иконки ОБЪЕКТОВ и ПЕРСОНАЖЕЙ: размер гексагона (покрывают весь гекс)
• Текстуры земли: автоматически обрезаются по форме гексагона

═══════════════════════════════════════════════════════════
  ПРИМЕР:
═══════════════════════════════════════════════════════════

1. Создайте изображение monster.png (64x64 пикселей)
2. Поместите его в папку Icons/
3. Перезагрузите игру
4. Монстры теперь будут отображаться с вашей иконкой!

═══════════════════════════════════════════════════════════

Если вы хотите вернуться к emoji, просто удалите соответствующий 
PNG файл из папки Icons/.

Приятной игры! 🎮
