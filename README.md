# Hex Quest

Пошаговая игра-исследование на гексагональной карте. Всё поле закрыто туманом; каждый клик открывает соседнюю клетку и сразу разыгрывает то, что под ней. Задача — набрать как можно больше очков, пока не кончились здоровье или еда.

## Правила

Три ресурса: **здоровье** (6 сердец, восстановить нельзя), **еда** и **мечи**.

| Клетка | Что делает |
|---|---|
| Трава, песок | Переход, +1 очко |
| Вода | Непроходима, только открывается |
| Лес | −1 еда, +2 очка (без еды платишь здоровьем) |
| Скала | −1 еда, +3 очка (без еды платишь здоровьем) |
| Монстр | −1 меч, +3 очка; без меча −1 здоровье и очков нет |
| Замок | +1 меч, одноразово |
| Дом | +1 еда, одноразово |

Очки за клетку дают один раз — это заставляет всё время идти в новое, а не топтаться по открытому. Ходить можно только на соседей уже открытых клеток.

## Генерация карты

Карта не разбрасывает клетки случайно, а рисует ландшафт: лес и горы растут группами, вода — озёрами, а монстры, дома и замки стоят поодиночке и редко оказываются рядом друг с другом.

## Запуск

Открыть `Hexagons.html` в браузере. Звуки лежат в `Sounds/`, иконки — в `Icons/`.

В папке `Versions/` — восемь предыдущих версий игры, от первого прототипа до текущей.

## Стек

Один HTML-файл: canvas, чистый JS, без библиотек.
